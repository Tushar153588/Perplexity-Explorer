06 / Educational Guide

How does perplexity work?

A beginner-friendly guide to language model probabilities and uncertainty metrics.

  • 1
    A language model predicts the next token. Given preceding context, the model produces a probability distribution across its entire vocabulary (over 50,000 possible tokens in GPT-2).
  • 2
    Every actual token receives a probability. When assessing a sentence, we look up the exact probability \(P(w_i)\) the model assigned to the token that actually appeared next.
  • 3
    Higher probability means low surprise. If the model predicted the word with probability 0.8, the reciprocal surprise is \(1/0.8 = 1.25\).
  • 4
    Lower probability means high surprise. If an unexpected word has probability 0.01, its reciprocal surprise is \(1/0.01 = 100\).
  • 5
    Perplexity combines these probabilities into one score. Perplexity calculates the geometric mean of the reciprocal probabilities across the sequence. Intuitively, it measures the effective "branching factor"—how many equally likely tokens the model is choosing between at each step.
  • 6
    Mathematically, perplexity is the exponential of cross-entropy. Instead of multiplying tiny numbers directly (which causes floating-point underflow), we sum their negative logarithms and take the exponential of the average.
PP(W) = exp( - 1/N · ∑ ln P(wᵢ) )
W The sequence of words or tokens \((w_1, w_2, \dots, w_N)\).
N The total count of evaluated tokens in the sequence.
wᵢ The \(i\)-th token in the sequence.
P(wᵢ) The model's probability for token \(w_i\) given preceding context.
∑ Sum over all evaluated tokens from \(i=1\) to \(N\).
ln Natural logarithm (base \(e\)).
exp Exponential function \(e^x\), the inverse of natural log.

Worked Example

Suppose a 3-token sentence has token probabilities: 0.5, 0.8, and 0.2.

  • Reciprocals: \(1/0.5 = 2.0\), \(1/0.8 = 1.25\), \(1/0.2 = 5.0\)
  • Product: \(2.0 \times 1.25 \times 5.0 = 12.5\)
  • Nth root (\(N=3\)): \((12.5)^{1/3} \approx 2.32\)
  • Perplexity = 2.32. The model was as uncertain on average as if choosing among ~2.3 options.
07 / Documentation

Technical Documentation

Technical implementation notes, mathematical stability, and runtime specifications.

Model Architecture

DistilGPT-2 is a 6-layer, 82-million parameter causal autoregressive transformer model trained by Hugging Face through distillation from GPT-2. It utilizes byte-pair encoding (BPE) with a vocabulary of 50,257 tokens.

Quantization (Q8)

The model is loaded using 8-bit quantization (dtype: 'q8'). This reduces the ONNX model file size from ~330MB down to ~85MB, allowing rapid download and low-latency execution inside web browser memory without loss of accuracy.

Numerically Stable Math

Softmax calculation subtracts the maximum logit before exponentiation to avoid floating-point overflow. Perplexity is computed in log-space as \(\exp(\text{mean}(-\ln P))\) to prevent arithmetic underflow on sequences of any length.

08 / About

About Perplexity Explorer

Privacy-first client-side machine learning for education and research.

Client-Side Privacy

All inference runs 100% locally in your browser using Transformers.js and WebAssembly. No text, prompts, or personal data are ever transmitted to any remote server or third-party API.

Local Model Caching

Weights are downloaded directly from the Hugging Face hub on the first run and stored securely in your browser's persistent CacheStorage and IndexedDB, enabling instant re-evaluations.

Educational Purpose

Designed for students, machine learning engineers, and researchers to develop an intuitive, visual, and mathematical grasp of autoregressive language generation, perplexity, and token confidence.
